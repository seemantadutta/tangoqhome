Tango Mode for Mixxx

DJ your milonga using Mixxx, with tango centered features.

Play your set the way you planned it: the queue holds its order and keeps every track so that you don’t lose your bearings, cortinas can be made to fade on their own, consistent gaps between tracks within a tanda, and you always know when the milonga will end - with safeguards so a stray key can’t kill the energy.

Built for the milonga

What Tango Mode adds

Everything here lives behind a single Tango Mode switch. Turn it off and it’s ordinary Mixxx.

The Set

Your set, kept in order

The Auto DJ list plays top to bottom and keeps every played track in place. A cursor marks where you are, so the tanda order you planned survives the night and the set stops cleanly at the end.

Look for: played tracks stay in the list and grey out, while the play cursor marks the next track up.

The Cortina

Cortinas fade themselves

Mark a track as a cortina and the engine fades it up, holds, fades it down, and leaves a clean silence on each side - no more reaching for the crossfader to clear the floor between tandas.

Look for: Setting the Cortina parameters in preferences (or the toolbar), then observing the cross fader automatically fading the cortina.

The Clock

Know when the night ends

See the set’s total length, its projected end time, and the time left at a glance - with an over/under against your target so you can land the milonga right on the hour.

Look for: the projected end time and time-left readout updating as the set plays.

The Floor

Guard the floor

Arm LIVE mode and a bumped keyboard can’t stop the music: disabling Auto DJ takes a deliberate two-step confirm, and the deck play/pause keys go quiet for the night.

Look for: the red countdown draining over the Auto DJ button when a stop is attempted.

The Queue

The queue, always in view

Float the Auto DJ queue into a docked, themed panel that stays put while you dig through your library for the next tanda.

Look for: the queue panel staying docked and live while the library view changes behind it.

The Booth

Tune the room live

Nudge cortina length from the toolbar as the night finds its mood, or mark a set unplayed to run it again from the top - the controls you reach for mid-milonga are right where you need them.

Look for: the cortina length changing straight from the toolbar, without pausing the set.

These builds aren’t code-signed, so your OS will warn you the first time. That’s expected for an independent fork - here’s how to open it anyway.

  1. Run the installer.

  3. Click Run anyway.

macOS installer

Download .dmg

SHA-256  paste checksum here

Gatekeeper blocking it (“unidentified developer” / “damaged”)?
  1. Drag Mixxx to Applications, then try to open it once (it’ll be blocked).
  2. Open System Settings → Privacy & Security, scroll down, click Open Anyway.
  3. If it says the app is “damaged”, open Terminal and run:
    xattr -dr com.apple.quarantine /Applications/Mixxx.app

Steps vary a little by macOS version. Proper notarization needs a paid Apple Developer account this fork doesn’t have.

Rather not run an unsigned build? Completely fair - read the source or build it yourself instead.

Questions

Frequently Asked Questions

Is this the official Mixxx?

No. Tango Mode is an independent, unofficial fork of Mixxx - not affiliated with or endorsed by the Mixxx project. It is built on Mixxx and released under the same GPL license; the official app lives at mixxx.org.

Why not just use another DJ app like djay Pro, Traktor or VirtualDJ?

You can, and you probably already do. But those apps are built for club DJs who beat-match and blend one track into the next for a dancefloor crowd. None of them understand a cortina, or that at a milonga every track stands on its own with no blending between them. Tango Mode adds exactly that missing, tango-specific handling.

What tango-specific features does it actually add?

It began with one wish: to stop tracks from vanishing out of the Auto DJ queue as they play. That snowballed into a set of related tools: cortina fading, a LIVE performance lock, tagging any track as a cortina, set-length and end-time estimates, and more. See the full list.

Does it change normal Mixxx? Do I lose anything?

No. Every Tango feature lives behind a single “Enable Tango DJ mode” switch in Preferences. With it off, the app behaves exactly like standard Mixxx, so you give up nothing by using this build.

Will my existing library, tracks and controllers work?

Yes. It is Mixxx under the hood (version 2.5.6), so your music library, track analysis, controller mappings and settings all work just as they do in the official build.

Why does my computer warn me about the installer? Is it safe?

Because these builds are not code-signed (that needs a paid developer certificate this project does not have), Windows SmartScreen and macOS Gatekeeper flag them as coming from an unknown developer. It is not malware: the full source is public and you can build it yourself. The Download section has the exact click-through steps.

Which platforms does it run on?

Windows and macOS. Linux users can build from source for now; packaged Linux builds may follow.

Is it free?

Yes, free and open source under the GNU GPL. If it earns a place in your booth you are welcome to chip in via the donate link, but that is entirely optional.

Will these features come to official Mixxx?

Maybe. This is a fork built for one specific tango workflow; some pieces might make sense upstream as optional settings, and that conversation is open with the Mixxx project. For now, this fork is where they live.

How do I report a bug or suggest a feature?

Open an issue on the fork’s GitHub via the Report a bug link. Reports that include your OS and the steps to reproduce are the most helpful.

Support the project

Tango Mode is free for the tango community and always will be. If it earns its place in your booth and you’d like to chip in, it’s appreciated - and entirely optional.
